## Documentación oficial

- [Build skills](https://learn.chatgpt.com/docs/build-skills), consultado por redirección de `https://developers.openai.com/codex/skills/`: metadatos `name` y `description`, instrucciones progresivas y recursos. Se preserva la instalación nativa del entorno Work; no se agrega un plugin o dependencia remota innecesaria.
- [PyMuPDF Page API](https://pymupdf.readthedocs.io/en/latest/page.html): texto, trazados y rasterización. Ventaja: mismo motor para geometría y evidencia. [Licencia](https://pymupdf.readthedocs.io/en/latest/about.html): verificar términos AGPL/comerciales antes de distribuir una aplicación integrada.
- [ezdxf ODA adapter](https://ezdxf.readthedocs.io/en/stable/addons/odafc.html): necesita ODA File Converter instalado para DWG. [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter): opción local a evaluar por licencia, sistema operativo y archivos de prueba.

## Desarrollar desde cero

Contratos de procedencia, selección revisada, calibración regional, reglas con variables dimensionadas, bloqueo de revisiones y duplicados, cotejos explícitos, consolidación con fuentes y visor separado. No se incorporan decisiones de diseño eléctrico. La extensibilidad se obtiene mediante tipos de datos y adaptadores, no agregando patrones de símbolos al núcleo.

## Evidencia que falta

No se ejecutaron benchmarks de terceros, conversores CAD ni modelos de CV. No se verificó precisión sobre símbolos reales de un proyecto de referencia: los DWG requieren conversión. No se declara equivalencia con herramientas comerciales. Las versiones mínimas de dependencias son rangos de compatibilidad, no una certificación de todas sus versiones; registrar versiones efectivas al ejecutar doctor y pruebas.
